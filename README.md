# 青才轨道 Demo V2

AI驱动的苏州青年职业发展路线图 Demo。核心链路：简历/画像输入 → 首岗与产业轨道 → 技能补齐 → 苏州政策礼包 → 三年留苏计划 → 留才预警 → 政府驾驶舱 → 专业报告。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 说明

- 本版本为参赛演示原型，不连接真实政府接口。
- 内置苏州政策样本，仅作演示规则库，正式申报需替换为主管部门官方政策文本和实时申报口径。
- 简历上传支持 DOCX / PDF / TXT 的基础文本解析；复杂版式可能解析不完整，可用侧边栏手动校准。
